# Authors and acknowledgements

The standalone SGHF package was written and is maintained by Lorenz Gaertner.

Sasha Glazov and Cyrille Praz created the original SGHF implementation and
concepts used in the `b2hnunubar_ITA` analysis repository. This package is a
clean rewrite with their permission; it removes analysis-specific plotting,
blinding, and Belle II dependencies while preserving the core
linear-Gaussian fitting approach.
